# Research evidence boundaries

| Capability | Current evidence | Boundary |
| --- | --- | --- |
| Offline composition | Python regression suite and deterministic fixtures | No cloud account or device write |
| Renderer security | IPC ownership, navigation, CSP, traversal and symlink tests | Main-process raw sockets require separate audit |
| Code generation | Typed request, confinement, concurrency, atomic cleanup and hash tests | One-operation local research template in the minimum proof |
| Local provider pipeline | Generated Maven build, assigned loopback port, local catalog and real Logic Engine/TinyRPC invocation | Requires pinned sibling component artifacts |
| Native application | Real BrowserWindow/preload/IPC self-check | Exact tested host and commit only |
| Unpacked application | Copied native executable starts production `resources/app` | Technical preview; no installer or signing claim |
| Cross-platform | Mandatory macOS ARM64, Linux X64 and Windows X64 exact-head workflow | Complete only when all jobs pass the same commit |

The historical catalog acquisition and automation adapters are retained as optional
research adapters. Their presence is not evidence that remote services remain stable,
that a third-party account authorized a mutation, or that physical devices were tested.

The code generator provenance record names the historical source commit and file hashes.
It records a history-preserving consolidation, not a claim that the repaired local
pipeline existed in the historical version.
